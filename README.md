# สื่อ AR เบาหวานและไตในผู้สูงอายุ

เว็บ AR ที่ใช้ได้กับมือถือทุกเครื่องโดยไม่ต้องติดตั้งแอป ผู้ใช้สแกน QR Code แล้วส่องกล้องไปที่ภาพปกในคู่มือ ภาพ 3 มิติจะลอยขึ้นบนหน้ากระดาษ พร้อมเสียงบรรยายภาษาไทยและคำบรรยายใต้ภาพ

- **เรื่องที่ 1** ส่องภาพปก "โรคเบาหวานชนิดที่ 2 ในผู้สูงอายุ" (`markers/m1.png`)
- **เรื่องที่ 2** ส่องภาพ "ภาวะไตเสื่อมจากโรคเบาหวาน" (`markers/m2.png`)
- **เรื่องที่ 3** ส่องภาพปก "การจัดการตนเองและครอบครัว" (`markers/m3.png`)

ไฟล์ `markers/print-markers.pdf` คือภาพทั้ง 3 ขนาด A4 สำหรับพิมพ์ทดสอบ

## ขั้นตอนที่ 1: นำเว็บขึ้นอินเทอร์เน็ตฟรีด้วย GitHub Pages

ใช้เวลาประมาณ 15 นาที ทำผ่านเว็บเบราว์เซอร์บนคอมพิวเตอร์ได้ทั้งหมด ไม่ต้องเขียนโปรแกรม

1. **สมัครบัญชี** ที่ https://github.com (ฟรี) ชื่อผู้ใช้จะเป็นส่วนหนึ่งของที่อยู่เว็บ
2. **สร้างที่เก็บไฟล์ (repository)**
   - กดปุ่ม **+** มุมขวาบน แล้วเลือก **New repository**
   - ช่อง Repository name ใส่ชื่อภาษาอังกฤษ เช่น `ar-diabetes`
   - เลือก **Public** แล้วกด **Create repository**
3. **อัปโหลดไฟล์รอบที่ 1** (ไฟล์หลัก)
   - ในหน้าที่เก็บไฟล์ กดลิงก์ **uploading an existing file**
   - แตกไฟล์ zip ที่ได้รับ เปิดโฟลเดอร์ `webar` แล้ว **ลากทุกอย่างยกเว้นโฟลเดอร์ `audio1` และ `audio2`** ไปวางในหน้าเว็บ (มีโฟลเดอร์ `lib`, `markers`, `media`, `docs` และไฟล์ `index.html`, `app.js`, `data.js`, `style.css`, `targets.mind`, `qr.html`, `README.md`)
   - รอให้ไฟล์ขึ้นครบ แล้วกด **Commit changes**
4. **อัปโหลดรอบที่ 2 และ 3** (เสียงบรรยาย)
   - กด **Add file** แล้วเลือก **Upload files** จากนั้นลากโฟลเดอร์ `audio1` ทั้งโฟลเดอร์มาวาง แล้วกด **Commit changes**
   - ทำซ้ำกับโฟลเดอร์ `audio2`
   - ที่ต้องแบ่งรอบ เพราะ GitHub รับได้ครั้งละไม่เกิน 100 ไฟล์
5. **เปิดเป็นเว็บไซต์**
   - ไปที่ **Settings** แล้วเลือก **Pages** ที่เมนูด้านซ้าย
   - ช่อง Source เลือก **Deploy from a branch**
   - ช่อง Branch เลือก **main** และ **/(root)** แล้วกด **Save**
   - รอ 1–3 นาที แล้วกดรีเฟรช ด้านบนจะแสดงที่อยู่เว็บ เช่น `https://ชื่อผู้ใช้.github.io/ar-diabetes/`

> เว็บต้องเปิดผ่าน **https** เท่านั้น ไม่อย่างนั้นมือถือจะไม่ยอมเปิดกล้อง ซึ่ง GitHub Pages เป็น https ให้อยู่แล้ว

## ขั้นตอนที่ 2: ทำ QR Code แล้วพิมพ์

1. เปิด `https://ชื่อผู้ใช้.github.io/ar-diabetes/qr.html`
2. หน้านี้สร้าง QR Code ของเว็บคุณให้อัตโนมัติ กดปุ่ม **พิมพ์** แล้วตัดป้ายไปติดในคู่มือ เช่น หน้าแรก หรือข้างภาพปกของแต่ละเรื่อง

## ขั้นตอนที่ 3: ทดสอบก่อนแจกจริง

- **iPhone:** สแกน QR ด้วยแอปกล้อง แล้วเปิดใน Safari
- **Android:** สแกน QR ด้วยแอปกล้องหรือ Google Lens แล้วเปิดใน Chrome
- กด **เริ่มส่องกล้อง** แล้วกด **อนุญาต** จากนั้นส่องภาพปกให้เห็นทั้งภาพ ห่างประมาณ 25–40 ซม.
- ทดสอบโดยไม่ต้องพิมพ์ก็ได้ เปิดภาพใน `markers/` บนจอคอมพิวเตอร์ แล้วใช้มือถือส่องที่จอ
- ควรให้ผู้สูงอายุ 3–5 คนลองสแกนเองก่อนใช้จริง แล้วสังเกตว่าติดขัดตรงไหน

**เคล็ดลับให้สแกนติดง่าย:** พิมพ์สี ภาพชัด ไม่สะท้อนแสง วางกระดาษเรียบ และอยู่ในที่แสงสว่างพอ ภาพที่พิมพ์ต้องเหมือนไฟล์ใน `markers/` (ไม่ครอป ไม่ใส่กรอบทับ ไม่เปลี่ยนสี)

## สิ่งที่ผู้ใช้จะเห็น

- **เมื่อส่องติด** มีเสียงแจ้ง มือถือสั่นเบา ๆ วงแสงกระจายบนภาพปก และภาพ 3 มิติเด้งขึ้นมาบนหน้ากระดาษ จากนั้นเสียงบรรยายเริ่มอ่านเอง
- **ภาพไม่หาย:** ถ้ายกกล้องออกจากหนังสือ ภาพจะลอยค้างหน้าจอให้ดูต่อได้ ส่องกลับไปที่ภาพปกเมื่อไร ภาพจะกลับไปวางบนกระดาษเอง
- **ลากนิ้ว** เพื่อหมุนภาพ ใช้สองนิ้วเพื่อซูม แตะลูกบอลหรือวงล้อเพื่อเลือกหัวข้อ
- **แถบด้านล่าง** มีปุ่มเล่นหรือหยุด ปุ่มฟังซ้ำ และหัวข้อย่อย แตะแถบเพื่อขยายอ่านเนื้อหาเต็ม ข้อความที่กำลังอ่านจะไฮไลต์สีเหลือง
- **ไม่มีคู่มือ?** กด "ดูได้เลยโดยไม่ต้องส่อง" เพื่อเลือกเรื่องและดูภาพ 3 มิติลอยหน้าจอ

## โมเดล 3 มิติ (เวอร์ชัน 2)

โมเดลทั้ง 11 ชิ้นสร้างด้วยโค้ดใน `models.js` ไม่ต้องโหลดไฟล์โมเดลแยก จึงเปิดเร็ว ทุกชิ้นใช้วัสดุแบบ PBR (มีเงาสะท้อนและผิวสัมผัส) และยืนบนแท่นเซรามิกแบบเดียวกัน

| ฉาก | โมเดล |
|---|---|
| รู้จักโรค | หลอดเลือดผ่าครึ่ง มีเม็ดเลือดแดงและผลึกน้ำตาลไหลผ่าน, เครื่องวัดน้ำตาลแสดงค่า 235 และไอคอนอวัยวะที่ได้รับผลกระทบ |
| กินพอดี | จานเซรามิกแบ่งสัดส่วน ผัก ½ ข้าวกล้อง ¼ ปลาและเต้าหู้ ¼ พร้อมชามผลไม้และแก้วน้ำ |
| ขยับร่างกาย | ตัวละครผู้สูงอายุ (ผมขาว ใส่แว่น มีสีหน้า) สาธิตท่า พร้อมเก้าอี้พยุง |
| กินยาตามสั่ง | กล่องยารายสัปดาห์ แยกช่องเช้า กลางวัน เย็น และก่อนนอน, นาฬิกา และขวดยาที่มีฉลาก |
| ดูแลใจ | ผู้สูงอายุนั่งฝึก SKT ท่าที่ 1 หงายฝ่ามือบนตัก หายใจเข้านับ 3 ออกนับ 5 ตามคู่มือ |
| ไตเสื่อมจากอะไร | ไตผ่าครึ่ง เห็นเนื้อไตชั้นนอก พีระมิด และกรวยไต พร้อมแว่นขยายตัวกรองในไต (โกลเมอรูลัส) |
| ค่า eGFR | หน้าปัดวัดค่า 6 ระยะ (G1–G5) มีเข็มชี้ตามค่าที่เลื่อน |
| 10 วิธีดูแลไต | ไอคอน 10 แบบหมุนรอบไต แตะเลือกได้ |
| สิ่งที่ทำประจำ | คลิปบอร์ดพร้อมไอคอนและช่องติ๊ก |
| 6 ขั้นตอน | วงล้อที่พิมพ์ชื่อขั้นตอนบนแต่ละช่อง ขั้นที่เลือกยกขึ้นเป็นสีทอง |
| ครอบครัวช่วยได้ | ยาย ลูกสาว และหลาน พร้อมกล่องคำพูด สีหน้ายายเปลี่ยนตามวิธีพูด |

**ไฟล์ `.glb` สำหรับนำไปใช้ต่อ:** อยู่ในโฟลเดอร์ `models-glb/` ผ่านการตรวจด้วย glTF Validator แล้ว (ไม่มีข้อผิดพลาด) เปิดได้ใน Blender, PowerPoint (แทรก > โมเดล 3 มิติ), Windows 3D Viewer หรือ https://gltf-viewer.donmccurdy.com และนำไปใช้กับเครื่องมือ AR อื่นได้

**ประสิทธิภาพ:** เมื่อเปิดกล้อง ภาพ 3 มิติจะวาดไม่เกิน 30 ภาพต่อวินาที เพื่อเหลือกำลังเครื่องให้ระบบจับภาพ ถ้ามือถือทำงานไม่ทัน ระบบจะลดความละเอียดของภาพลงเองโดยอัตโนมัติ

## การปรับแต่งภายหลัง

### ใส่วิดีโอออกกำลังกายจริง
ถ่ายวิดีโอผู้สูงอายุทำท่าออกกำลังกาย บันทึกเป็นไฟล์ MP4 ขนาดไม่เกิน 25 MB (ความยาว 1–3 นาที ความละเอียด 720p กำลังดี) ตั้งชื่อว่า `exercise.mp4` แล้วอัปโหลดไว้ในโฟลเดอร์ `media/` ปุ่ม "ดูวิดีโอ" ในหัวข้อ "ขยับร่างกาย" จะเล่นวิดีโอนี้แทนหุ่น 3 มิติโดยอัตโนมัติ
(วิธีอัปโหลด: ในหน้า GitHub เปิดโฟลเดอร์ `media` กด **Add file** แล้วเลือก **Upload files** ลากไฟล์วิดีโอมาวาง แล้วกด **Commit changes**)

### เปลี่ยนเสียงบรรยายเป็นเสียงคนจริง
เสียงที่ใส่ไว้สร้างด้วยโปรแกรมแปลงข้อความเป็นเสียง ถ้าต้องการเสียงนุ่มเป็นธรรมชาติ ให้อัดเสียงผู้บรรยายจริง
1. เปิด `docs/narration-script.csv` ด้วย Excel หรือ Google Sheets จะเห็นข้อความ 174 ประโยค พร้อมชื่อไฟล์ของแต่ละประโยค
2. อัดเสียงทีละประโยค บันทึกเป็น MP3 แล้วตั้งชื่อตามคอลัมน์ "ชื่อไฟล์" (เช่น `audio1/4dd42a544a.mp3`)
3. อัปโหลดไฟล์ทับของเดิมในโฟลเดอร์ `audio1` หรือ `audio2`

ผู้ใช้เลือกเสียงอ่านภาษาไทยของเครื่องได้จากปุ่มตั้งค่า ⚙ ด้วย ซึ่งใน iPhone และ Android ส่วนใหญ่มีเสียงผู้หญิงที่ฟังเป็นธรรมชาติ

### แก้ข้อความ
ข้อความทั้งหมดอยู่ใน `data.js` (บทบรรยายและคำบรรยายใต้ภาพ) และ `app.js` (ส่วนเนื้อหาในแผงอ่าน หาคำว่า `TOPICS`) ถ้าแก้ประโยคที่มีเสียง ให้อัดเสียงประโยคนั้นใหม่ด้วย

### เปลี่ยนภาพที่ใช้ส่อง
1. เปิดเครื่องมือแปลงภาพของ MindAR ที่ https://hiukim.github.io/mind-ar-js-doc/tools/compile
2. ใส่ภาพใหม่ 3 ภาพ **เรียงตามลำดับ** เรื่องที่ 1, 2, 3 แล้วกด Start
3. ดาวน์โหลดไฟล์ `targets.mind` มาอัปโหลดทับไฟล์เดิม และอัปโหลดภาพใหม่ทับ `markers/m1.png`, `m2.png`, `m3.png`

ภาพที่ดีควรมีรายละเอียดมาก สีตัดกัน และไม่มีพื้นที่สีเดียวกว้าง ๆ

## ไฟล์ในโปรเจกต์

| ไฟล์ / โฟลเดอร์ | หน้าที่ |
|---|---|
| `index.html`, `style.css` | หน้าจอและการจัดวาง |

| `docs/` | สคริปต์เสียงสำหรับอัดใหม่ |

## ข้อควรทราบก่อนเผยแพร่

- **ลิขสิทธิ์ภาพ:** ภาพปกและอินโฟกราฟิกที่ใช้เป็นภาพส่อง ต้องเป็นภาพที่ทีมมีสิทธิ์เผยแพร่ ถ้านำมาจากแหล่งอื่น ควรขออนุญาตก่อน หรือเปลี่ยนเป็นภาพที่ทำเอง
- **ความถูกต้องของเนื้อหา:** เนื้อหาเรื่องยาและการออกกำลังกายควรให้ผู้เชี่ยวชาญตรวจก่อนเผยแพร่สู่ประชาชน
- **ความเป็นส่วนตัว:** เว็บนี้ใช้กล้องเพื่อส่องภาพในเครื่องของผู้ใช้เท่านั้น ไม่บันทึกหรือส่งภาพจากกล้องไปที่ใด
